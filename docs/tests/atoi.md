# atoi 测试用例

覆盖 `cc_atoi` 的字符串到 32 位整数转换。被测接口见 [atoi](../atoi.md)。

## BASIC-ATOI-001 合法整数解析

- 状态：已实现
- 前置：无。
- 步骤：依次调用 `cc_atoi`：
  - `"0"`
  - `"123"`
  - `"-123"`
  - `"000123"`
  - `"2147483647"`
  - `"-2147483648"`
  - `"-0"`
- 预期：
  - `"0"` -> `0`
  - `"123"` -> `123`
  - `"-123"` -> `-123`
  - `"000123"` -> `123`
  - `"2147483647"` -> `2147483647`
  - `"-2147483648"` -> `-2147483648`
  - `"-0"` -> `0`
- 真值来源：规范（`docs/atoi.md`）。
- 平台：all
- 级别：quick
- 代码：`tests/basic.c` · `CC_CASE("BASIC-ATOI-001")`

## BASIC-ATOI-002 非法输入

- 状态：已实现
- 前置：无。
- 步骤：依次调用 `cc_atoi`：
  - `NULL`
  - `""`
  - `"+123"`
  - `"12a3"`
  - `" 123"`
  - `"-"`
- 预期：以上输入全部返回 `0`。
- 真值来源：规范（空指针、空字符串、非数字字符返回 0；`+` 不属于支持的符号）。
- 平台：all
- 级别：quick
- 代码：`tests/basic.c` · `CC_CASE("BASIC-ATOI-002")`

## BASIC-ATOI-003 溢出饱和与长前导零

- 状态：已实现
- 前置：无。
- 步骤：依次调用 `cc_atoi`：
  - `"2147483648"`
  - `"-2147483649"`
  - `"10000000000000000000"`
  - `"-10000000000000000000"`
  - `"0000000000000000000000000001"`
  - `"-0000000000000000000000000005"`
- 预期：
  - `"2147483648"` -> `2147483647`（正溢出饱和到 `INT32_MAX`）
  - `"-2147483649"` -> `-2147483648`（负溢出饱和到 `INT32_MIN`）
  - `"10000000000000000000"` -> `2147483647`
  - `"-10000000000000000000"` -> `-2147483648`
  - 超长前导零后分别为 `1` 和 `-5`
- 真值来源：规范（溢出饱和规则）。
- 平台：all
- 级别：quick
- 代码：`tests/basic.c` · `CC_CASE("BASIC-ATOI-003")`
