# color_print 测试用例

覆盖 `color_print` 的返回值契约和人工颜色核对。被测接口见 [color_print](../color_print.md)。

## COLOR-AUTO-001 可见字符计数

- 状态：已实现
- 前置：无。
- 步骤：调用 `color_print`，检查返回值等于输出中的可见字符数；
  返回值只统计可见字符；`%c_XY` 颜色控制符和 ANSI 转义码按 0 计。
- 预期：
  - `"hello\n"` -> `6`
  - `"a\nb\n"` -> `4`
  - 颜色控制符 + `"OK\n"` -> `3`
  - 颜色控制符 + `"%d\n", 7` -> `2`
  - 双向复位 + `"reset\n"` -> `6`
  - `"%c_20a%c_00b\n"` -> `3`
  - `"n=%d\n", 42` -> `5`
  - `"%d\n", -123` -> `5`
  - `"%u\n", 4294967295` -> `11`
  - `"%x\n", 0xABCD` -> `11`
  - `"%ld\n", 1234567890123` -> `14`
  - `"%s\n", "abc"` -> `4`
  - `"%s\n", NULL` -> `7`
  - `"%c\n", 'x'` -> `2`
  - `"%%\n"` -> `2`
  - `"%f\n", 1.5` -> `9`
  - `"%.2f\n", 3.14159` -> `5`
  - `"%c_GG\n"`（非法颜色）-> `5`
  - `"%c_"`（不完整转义，EOF）-> `2`
  - `"%c_\n"`（不完整转义，换行）-> `3`
- 真值来源：规范（返回值为可见字符数）；非法/不完整转义的兜底行为由实现约定。
- 平台：all
- 级别：quick
- 代码：`tests/color_print.c` · `CC_CASE("COLOR-AUTO-001")`

## COLOR-MANUAL-001 16x16 色块矩阵

- 状态：已实现
- 前置：终端支持 ANSI 颜色。
- 步骤：在全部自动套件之后输出 16x16 前景/背景颜色矩阵；输出后等待回车。
- 预期：每个格子的前景色与背景色组合正确；颜色不串到相邻格子。
- 真值来源：人工核对。
- 平台：all（终端颜色能力影响肉眼核对；自动断言照常执行）
- 级别：quick
- 代码：`tests/manual.c` · `CC_MANUAL("COLOR-MANUAL-001")`
