# 红黑树内核测试用例

覆盖 `cc_rbt_core` 的插入、检索、中序遍历、删除和红黑不变量。被测接口见 [cc_rbt_core](../cc_rbt_core.md)。

## RBT-BASE-001 空树

- 状态：已实现
- 前置：初始化用户侧节点结构和 `CC_RbtOps`，根为 `NULL`。
- 步骤：检索、删除；用非法参数插入；用空回调遍历。
- 预期：检索/删除返回 `NULL`；空树满足红黑不变量；非法插入返回非 0；
  空回调遍历返回非 0。
- 真值来源：规范 + 红黑不变量。
- 平台：all
- 级别：quick
- 代码：`tests/rbt_core.c` · `CC_CASE("RBT-BASE-001")`

  重复键插入被拒绝且树不变；删除返回原节点、树变空并触发根通知；
  删除后检索落空。
