# crc 测试用例

覆盖 `cc_crc32` 的标准向量、空输入、NULL、种子续算和分块续算。被测接口见 [crc](../crc.md)。

## BASIC-CRC-001 CRC-32 标准向量与续算

- 状态：已实现
- 前置：无。
- 步骤：
  1. 计算标准测试向量；
  2. 计算空输入、NULL、`size == 0` 的返回值；
  3. 对同一段 `"123456789"` 按不同切分方式分块续算。
- 预期：
  - `"123456789"` -> `0xCBF43926`
  - `"a"` -> `0xE8B7BE43`
  - `"abc"` -> `0x352441C2`
  - `"The quick brown fox jumps over the lazy dog"` -> `0x414FA339`
  - 单个 `0x00` 字节 -> `0xD202EF8D`
  - 空输入、`NULL` 且 `size == 0` -> `0`
  - `NULL` 且 `size > 0` -> `0`
  - `size == 0` 且种子为 `0x12345678` -> 返回原种子
  - 任意切分（4+5、1+8、3+6、9+空块）结果均等于一次性计算值
- 真值来源：规范（IEEE 802.3 CRC-32 标准向量与续算定义）。
- 平台：all
- 级别：quick
- 代码：`tests/basic.c` · `CC_CASE("BASIC-CRC-001")`
