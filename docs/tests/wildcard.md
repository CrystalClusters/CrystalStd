# wildcard 测试用例

覆盖 `cc_wildcard` 的精确匹配、`?`、`*`、组合模式和错误输入。被测接口见 [wildcard](../wildcard.md)。

## BASIC-WILDCARD-001 通配符匹配

- 状态：已实现
- 前置：无。
- 步骤：依次调用 `cc_wildcard(pattern, str)`，覆盖：
  - 空串、精确匹配、大小写；
  - `?` 的单字节、空串、多字节、中间位置；
  - `*` 的空串、前缀、后缀、中间、连续多个、全 `*`；
  - 文件名模式 `*.c`、`*.*`、`?ain.c`；
  - `*` / `?` 遇到 `/`；
  - NULL 参数。
- 预期：
  - 空模式只匹配空串；
  - 匹配区分大小写；
  - `?` 恰好匹配一个字节，不匹配空串；
  - `*` 匹配任意长度（含空），多个 `*` 与相邻 `*` 正常；
  - `*` / `?` 对 `/` 没有特殊语义；
  - 任一参数为 `NULL` 时返回 `CCFALSE`。
- 真值来源：规范（`docs/wildcard.md`）。
- 平台：all
- 级别：quick
- 代码：`tests/basic.c` · `CC_CASE("BASIC-WILDCARD-001")`
