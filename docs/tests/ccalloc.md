# ccalloc 测试用例

覆盖 `ccalloc` 的分配、调整、注释、对齐、段管理、空闲链表、泄漏检测和压力。
被测接口见 [ccalloc](../ccalloc.md)。

## ALLOC-BASIC-001 基础分配与释放

- 状态：已实现
- 前置：重新初始化分配器。
- 步骤：分配 1 字节并写注释；读写用户区；执行空操作、超大分配、释放；
  再在未初始化状态下分配。
- 预期：分配非空且注释可查询；用户区可读写；`(NULL, 0)` 返回 `NULL`；
  超大尺寸被拒绝；释放返回 `NULL` 且注释失效；未初始化时分配返回 `NULL`；
  用例结束无泄漏。
- 真值来源：规范 + 分配器不变量。
- 平台：all
- 级别：quick
- 代码：`tests/ccalloc.c` · `CC_CASE("ALLOC-BASIC-001")`
