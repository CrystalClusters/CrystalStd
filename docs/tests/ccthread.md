# ccthread 测试用例

覆盖线程创建、查询、等待、锁和节点回收。被测接口见 [ccthread](../ccthread.md)。

## THREAD-SINGLE-001 单线程生命周期与数据传递

- 状态：已实现
- 前置：无。
- 步骤：创建线程，线程入口阻塞在闸门；确认创建成功和存活状态后放行；
  等待线程结束，检查入口收到的用户数据、线程 ID 和结束状态。
- 预期：创建返回非 0 ID；刚创建时 `cc_thread_status == 1`；入口收到传入的 `data`
  和与创建返回值一致的线程 ID；等待后入口已执行；结束后状态为 `0`。
- 真值来源：规范（线程生命周期契约）。
- 平台：all
- 级别：quick
- 代码：`tests/ccthread.c` · `CC_CASE("THREAD-SINGLE-001")`
